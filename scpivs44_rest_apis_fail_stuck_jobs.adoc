= 중단된 작업을 실패로 표시하는 REST API
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
SnapCenter Plug-in for VMware vSphere 사용하여 VMware vSphere 클라이언트 작업에 대한 작업 ID를 찾으려면 VMware vSphere에 대한 REST API 호출을 사용해야 합니다.  이러한 REST API는 SnapCenter Plug-in for VMware vSphere 에 추가되었습니다.

각 REST API의 경우 REST API 앞에 \https://<server>:<port>`를 추가하여 완전한 엔드포인트를 형성합니다.

작업 섹션에서 다음 REST API를 사용하여 실행 상태에 멈춘 작업을 실패 상태로 변경합니다.

|===
| REST API | 댓글 


| `/4.1/jobs/{id}/failJobs` | 실행 상태에 멈춘 작업의 ID를 전달하면, `failJobs` 해당 작업을 실패로 표시합니다. 실행 상태에 갇힌 작업을 식별하려면 작업 모니터 GUI를 사용하여 모든 작업의 상태와 작업 ID를 확인하세요. 
|===
