= MySQL 데이터베이스의 최신 백업을 복원합니다.
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
유지 관리 콘솔을 사용하여 SnapCenter Plug-in for VMware vSphere 의 MySQL 데이터베이스(NSM 데이터베이스라고도 함)의 최신 백업을 복원할 수 있습니다.

.단계
. 유지 관리 콘솔 창을 엽니다.
+
link:scpivs44_access_the_maintenance_console.html["유지 관리 콘솔에 액세스"^] .

. 메인 메뉴에서 *1) 애플리케이션 구성* 옵션을 입력합니다.
. 애플리케이션 구성 메뉴에서 *6) MySQL 백업 및 복원* 옵션을 입력합니다.
. MySQL 백업 및 복원 구성 메뉴에서 *4) MySQL 백업 복원* 옵션을 입력합니다.
. "최근 백업을 사용하여 복원"이라는 프롬프트에서 *y*를 입력한 다음 *Enter*를 누릅니다.
+
백업된 MySQL 데이터베이스가 원래 위치로 복원됩니다.
