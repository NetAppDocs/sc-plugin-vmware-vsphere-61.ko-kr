= 업그레이드 경로
:allow-uri-read: 


[role="lead"]
업그레이드할 수 있는 SnapCenter Plug-in for VMware vSphere 버전은 현재 실행 중인 버전에 따라 달라집니다.

[NOTE]
====
SnapCenter Plug-in for VMware vSphere 으로 업그레이드하는 것은 VMware vCenter Server 7 업데이트 1 이상 버전에서만 지원됩니다.  버전 7 업데이트 1 이전의 VMware vCenter 서버의 경우 SCV 4.7을 계속 사용해야 합니다.
