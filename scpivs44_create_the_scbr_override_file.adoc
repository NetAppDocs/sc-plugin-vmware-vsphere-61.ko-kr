= scbr.override 구성 파일을 만듭니다.
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
그만큼 `scbr.override` 구성 파일은 SnapCenter 애플리케이션 기반 데이터 보호 작업을 지원하는 환경에서 SnapCenter Plug-in for VMware vSphere 에서 사용됩니다.

. 로 가다 `/opt/netapp/scvservice/standalone_aegis/etc/scbr/scbr.override-template` .
. 복사하다 `scbr.override-template` 파일을 새 파일로 변환 `scbr.override` 에서 `\opt\netapp\scvservice\standalone_aegis\etc\scbr` 예배 규칙서.
