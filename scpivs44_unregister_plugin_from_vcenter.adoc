= vCenter에서 SnapCenter Plug-in for VMware vSphere 취소
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
연결 모드에 있는 vCenter에서 SnapCenter Plug-in for VMware vSphere 서비스를 중지하면, 다른 연결된 vCenter에서 SnapCenter Plug-in for VMware vSphere 서비스가 실행 중이더라도 연결된 모든 vCenter에서 리소스 그룹을 사용할 수 없습니다.

SnapCenter Plug-in for VMware vSphere 수동으로 등록 취소해야 합니다.

.단계
. SnapCenter Plug-in for VMware vSphere 서비스가 중지된 연결된 vCenter에서 MOB(Managed Object Reference) 관리자로 이동합니다.
. 속성 옵션에서 값 열에 *content*를 선택한 다음, 다음 화면에서 값 열에 *ExtensionManager*를 선택하여 등록된 확장 프로그램 목록을 표시합니다.
. 확장 프로그램 등록 취소 `com.netapp.scv.client` 그리고 `com.netapp.aegis` .
