= 감사 로그를 생성하는 REST API
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Swagger REST API와 SCV 플러그인 사용자 인터페이스에서 감사 로그 세부 정보를 수집할 수 있습니다.

다음은 Swagger REST API입니다.

. GET 4.1/audit/logs: 모든 로그에 대한 감사 데이터 가져오기
. GET 4.1/audit/logs/{filename}: 특정 로그 파일에 대한 감사 데이터 가져오기
. POST 4.1/audit/verify: 감사 로그 검증을 트리거합니다.
. GET 4.1/audit/config: 감사 및 syslog 서버 구성 가져오기
. PUT 4.1/audit/config: 감사 및 syslog 서버 구성 업데이트


SnapCenter Plug-in for VMware vSphere 사용하여 VMware vSphere 클라이언트 작업에 대한 감사 로그를 생성하려면 VMware vSphere에 대한 REST API 호출을 사용해야 합니다.

각 REST API에 대해 다음을 추가합니다. `\https://<server>:<port>/api` REST API의 전면에 위치하여 완전한 엔드포인트를 형성합니다.

다음 REST API를 작업 섹션에서 사용하면 작업에 대한 자세한 정보를 얻을 수 있습니다.

|===
| REST API | 댓글 


| `4.1/audit/logs` | 무결성 데이터가 포함된 감사 로그 파일을 반환합니다. 


| `4.1/audit/logs/{filename}` | 무결성 데이터가 포함된 특정 감사 로그 파일 가져오기 


| `4.1/audit/verify` | 감사 검증을 트리거합니다 


| `4.1/audit/syslogcert` | syslog 서버 인증서를 업데이트합니다 
|===
